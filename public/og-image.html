Generador de og-image (1200×630)

⚠️ Ábrelo desde el servidor de desarrollo, no con doble clic. Con npm run dev corriendo, entra en http://localhost:5173/og-image.html. Si lo abres como archivo (file://) el navegador bloquea la exportación.

Pasos: 1) Guarda tus 4 capturas en public/assets/og/ como 1.png, 2.png, 3.png, 4.png. 2) Con el dev server abierto, entra en http://localhost:5173/og-image.html. 3) Pulsa Descargar. 4) Mueve el PNG a public/og-image.png y sube el proyecto.
